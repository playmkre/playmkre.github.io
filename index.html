🗺 화면별 역할 안내
① 대시보드
  • 종합 현황: 생산/품질 요약 + 우선 확인 대상
  • 장비 생산현황: 호기별 진행 상태 (대시보드 보조)
  • 팀별 업무 현황: 팀/공정 분포 + 미배정 파악
② 일정 관리
  • 생산일정 관리: 캘린더/간트/배치 전체 조회
  • 스케줄 변동 이력: 세션 변경 이력 (서버 아님)
  • 모델별 상세: 모델 기준 단계 흐름
  • 기간별 분석: 기간 단위 stacked bar 분포
③ 생산 관리
  • 종합 파악: 운영 포커스 + 우선순위 관제
  • 생산인원 입력: 입력 shell (저장 비활성)
  • 공정 현황: 공정 flow + 병목 + 호기 matrix
④ 품질 관리
  • 불량 관리 센터: 품질 엑셀 업로드 → Raw 검수
  • 품질 대시보드: 호기/모델 기준 불량 현황
  • 품질 분석센터: Pareto/Heatmap 분석
⑤ 데이터 관리
  • 장비 데이터: 호기·모델 master 정규화 확인
  • 업로드 이력: 세션 파일 업로드/파싱 이력
  • 데이터 검증: 생산일정 날짜·호기·공정 검증
  • 파일 매핑: 컬럼 매핑 상태 + 표준 필드 연결 확인
⚠ 데이터 주의사항
  • 일요일 자동 보정 없음 — 원본 확인 필요
  • 원본 데이터 조용한 수정 없음
  • 팀/담당 필드 없으면 공정 기준 대체
  • 품질관리는 별도 파서/Raw 검수 흐름
  • 새로고침 시 모든 세션 데이터 초기화
