# ADMIN v0.4.1 EMPTY_SCHEMA_START

이 버전은 v0.4에 포함되었던 연결 확인용 예시/seed 데이터를 제거한 관리자 포털 단독 개발본입니다.

## 기준
- 실제 운영 데이터가 없는 상태를 기준으로 합니다.
- 예시 사용자/팀/다운로드 요청/공지/감사 로그를 자동 생성하지 않습니다.
- `ODIAdminStore.seedDefaults()`는 빈 운영 스키마만 초기화합니다.
- 사용자 포털 파일은 수정하지 않습니다.

## 다음 단계
실제 사용자/팀/역할 CRUD는 v0.5에서 빈 Store에 입력되는 방식으로 구현합니다.
